# WebAR-тренажёр «Вертикально-сверлильный станок 2Н135»

Курсовая работа по дисциплине «Разработка кроссплатформенных приложений дополненной реальности» (РТУ МИРЭА).

Сценарий: подготовка станка и сверление отверстия, 7 шагов — СИЗ, осмотр, закрепление заготовки, установка сверла и снятие ключа, выбор режимов, пробный пуск, сверление и остановка.

## Запуск

Открыть ссылку GitHub Pages на телефоне или компьютере. Обучение проходится в режиме 3D; для режима AR нужны камера и распечатанный маркер `public/targets/marker.png`.

Локально:

```
npm install
npm run dev
```

Для проверки на телефоне по HTTPS в общей Wi-Fi сети:

```
npm run dev:phone
```

## Стек

Vite, TypeScript, three.js, GSAP, MindAR (image tracking). Работает в iOS Safari и Android Chrome.

## Состояние

Готов этап обучения. Демо-режим и режим проверки знаний — в планах.

Модель станка собрана процедурно в коде: готовой бесплатной GLB-модели 2Н135 найти не удалось.
